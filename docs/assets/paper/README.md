# Paper Figure Assets

Team-supplied figures from the submitted IEEE Aerospace 2027 paper, added on
10 October 2026. The standalone PDFs are unchanged originals; PNGs are rendered
previews for GitHub, not redrawn or regenerated scientific results. The Fig. 5
preview is a clipped rendering of the final manuscript, with its legend and
all three panels intact; its explanation is supplied in the main README.

To re-render from the repository root with Poppler:

```shell
pdftoppm -png -singlefile -scale-to-x 2400 -scale-to-y -1 docs/assets/paper/architecture.pdf docs/assets/paper/architecture
pdftoppm -png -singlefile -scale-to-x 1500 -scale-to-y -1 docs/assets/paper/receiver-supervisor.pdf docs/assets/paper/receiver-supervisor
pdftoppm -png -singlefile -scale-to-x 1500 -scale-to-y -1 docs/assets/paper/avoidance-geometry.pdf docs/assets/paper/avoidance-geometry
```

To render Fig. 5 from the team manuscript (not bundled), replace the input
filename with its local path. At 300 dpi, the rectangle below excludes the
table and surrounding prose but preserves the plot labels and legend:

```shell
pdftoppm -f 15 -l 15 -singlefile -r 300 -x 208 -y 720 -W 2125 -H 771 -png "IEEE_Aerospace_Conference_Paper (1).pdf" docs/assets/paper/encounter-results
```

The architecture is a functional diagram. For the exact closed-loop observation
emulation, UKF input and distinction between correction enable and receiver
power, see [model architecture](../../model-architecture.md).
The receiver diagram describes the nominal Reactive configuration, not the
Fixed-Time calendar or the always-powered Full GNSS comparator.
The Fig. 5 plot shows the manuscript's original five configurations and paired
simulation results. It is not a plot generated by a new public-model run.

These are project-team figure assets, not third-party references redistributed
under the source-code license. Superseded challenge figures are isolated under
`../history/` and [project history](../../history.md).
